# AgroWorld Blockchain (AWB)

## Overview
Agricultural marketplace platform with blockchain integration for transparent transactions and smart contract-based payments. Built with production-grade PHP/MySQL backend and modern JavaScript frontend.

## Tech Stack
- **Backend:** PHP, MySQL
- **Frontend:** JavaScript, HTML, CSS
- **Blockchain:** Integration for transparent, secure transactions

## Key Features
- Transparent agricultural marketplace
- Blockchain-based payment settlements
- Smart contract integration
- Real-time transaction tracking
- Secure buyer-seller interactions

## Getting Started
1. Clone the repo
2. Configure your database credentials in `.env`
3. Run database migrations
4. Start the development server
